# PGM Unity Labs

Репозиторий содержит 7 отдельных Unity-проектов с лабораторными работами по прототипированию игр.

## Лабораторные

- `GamePrototype_Lab1`
- `GamePrototype_Lab3_FPS`
- `GamePrototype_Lab4_Narrative`
- `GamePrototype_Lab5_Stealth`
- `GamePrototype_Lab6_PuzzleMechanics`
- `GamePrototype_Lab7_TerritoryControl`
- `GamePrototype_Lab8_AttentionCamera`

Каждая лабораторная открывается в Unity как отдельный проект: нужно выбрать папку конкретной лабораторной. В репозиторий добавлены только рабочие файлы проектов (`Assets`, `Packages`, `ProjectSettings`) и описания; кэш Unity и локальные настройки исключены.
